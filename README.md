# השראה לציור

אפליקציה (PWA) בעברית לאמא שמציירת לפי תמונות: מוצאים תמונות לציור, שומרים רעיונות באוספים,
מקבלים הצעות מהמשפחה, ומבקשים יצירה או עריכה של תמונה. מותקנת במסך הבית באייפון.

**כתובת (אחרי הפריסה):** https://elad-vibes.github.io/painting-inspiration/

## מי עושה מה
- **אמא** — הגלריה, האוספים, החיפוש, ההצעות מהמשפחה, ויצירה/עריכה בתוך תקרה.
- **המשפחה** — כל אחד לפי ההרשאות שלו: לשלוח לאמא תמונות, לצפות במה שהיא שיתפה, להגיב.
- **אלעד (אדמין)** — מזמין אנשים, קובע הרשאות ותקרות, ורואה שימוש והוצאה משוערת. לא רואה את התמונות.

## פרטיות — בכנות
- כל מה ששל אמא פרטי לה, עד שהיא מסמנת "לשתף עם המשפחה". זה נאכף במסד הנתונים עצמו
  (Row Level Security) ונבדק בבדיקות אוטומטיות.
- **בעל פרויקט ה-Supabase יכול טכנית לגשת לכל הנתונים** דרך לוח הבקרה. מסך האדמין באפליקציה
  מראה רק ספירות ושימוש, אבל זו הגבלה של האפליקציה, לא של בעל הפרויקט.
- תמונות מהרשת לא נשמרות אצלנו — רק קישור, שם היוצר והמקור.
- שליחת תמונה לעריכה בשירות חיצוני (Higgsfield) קורית רק בלחיצה של אמא, ואחרי הסבר.
  אם יש בתמונה אנשים — אזהרה ואישור נוסף. פירוט: `ART-PLAN.md` §4.

## איך זה בנוי
Vite + TypeScript (בלי framework) · Supabase: Postgres + RLS, Auth (קוד במייל, TOTP לאדמין),
Storage, Edge Functions (Deno) · GitHub Pages. אפיון: `ART-PLAN.md` · החלטות: `DECISIONS.md` ·
הקמה: `SETUP.md` · כללי עבודה: `AGENTS.md` · נכסים ורישיונות: `ASSETS.md`.
